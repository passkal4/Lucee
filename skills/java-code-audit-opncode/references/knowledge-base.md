# Java 代码审计核心知识库

## 1) SQL 注入（SQLi）
- 成因
  - 动态拼接 SQL（字符串拼接、`${}` 模板替换）包含用户可控输入。
  - ORM/Mapper 层绕过参数化查询。
- 危害
  - 数据泄露、越权查询、写入篡改、数据库接管。
- 防御
  - 强制参数化查询（PreparedStatement、MyBatis `#{}`）。
  - 最小权限数据库账号。
  - 对动态列名/排序字段使用白名单映射。

## 2) XXE
- 成因
  - XML 解析器启用外部实体/DTD，处理不可信 XML。
- 危害
  - 本地文件读取、SSRF、拒绝服务（实体膨胀）。
- 防御
  - 禁用 DTD 与外部实体。
  - 使用安全解析特性并统一封装 XML 工具。

## 3) 不安全反序列化
- 成因
  - 对不可信字节流/文本执行 Java 原生或第三方对象反序列化。
- 危害
  - RCE、任意方法调用、敏感信息篡改。
- 防御
  - 避免原生反序列化；使用 JSON + 严格类型白名单。
  - `ObjectInputFilter`/类白名单。
  - 对消息体进行签名校验。

## 4) SSRF
- 成因
  - 服务端根据用户输入发起 URL 请求，缺少目的地址限制。
- 危害
  - 探测内网、访问云元数据、横向移动。
- 防御
  - 协议/域名/IP 白名单。
  - 禁止访问回环、内网、链路本地地址。
  - 禁止自动重定向，二次解析最终目标。

## 5) SSTI
- 成因
  - 用户输入进入模板解析表达式或模板名称可控。
- 危害
  - 任意表达式执行、数据泄露、RCE。
- 防御
  - 模板与数据分离，禁止拼接模板。
  - 关闭危险表达式能力。
  - 对模板名使用固定映射。

## 6) XSS（服务端相关）
- 成因
  - 未根据上下文编码即回显不可信输入到 HTML/JS/URL。
- 危害
  - 会话劫持、凭证窃取、页面篡改。
- 防御
  - 输出编码（按 HTML/属性/JS/URL 上下文）。
  - 开启 CSP，设置 HttpOnly/SameSite Cookie。

## 7) 文件上传/读取
- 成因
  - 上传类型、扩展名、MIME、内容校验不完整；路径拼接可控。
- 危害
  - WebShell、任意文件写入/读取、路径穿越。
- 防御
  - 随机文件名 + 固定目录。
  - 校验真实文件类型（magic number）。
  - 规范化路径并校验父目录。

## 8) 命令注入
- 成因
  - 将用户输入拼接到系统命令（`Runtime.exec`, `ProcessBuilder`）中。
- 危害
  - 远程命令执行、主机控制权丢失。
- 防御
  - 禁止 shell 拼接，改为参数数组。
  - 对可选参数建立白名单枚举。
  - 进程执行账户最小权限。

## 通用审计判定维度
- 可控性：输入是否来自 HTTP/消息队列/外部存储并可被攻击者影响。
- 可达性：Source 到 Sink 是否存在可执行路径。
- 有效防护：Sanitizer 是否在正确上下文、正确顺序、无旁路。
- 影响面：数据敏感度、权限边界、是否可链式利用。
